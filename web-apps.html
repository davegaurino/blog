Web Apps

A selection of browser-based tools and small applications designed to solve practical problems with simple interfaces.

Latest Web Apps

Here are recent sample projects in this category.

TaskFlow Daily Planner

TaskFlow is a simple browser-based planner for organizing daily priorities without turning the page into a complicated project management system. Users can enter tasks, mark important items, group work by category, and check completed activities. The interface is designed to make the day visible at a glance, with the most important tasks appearing first. A lightweight version can store information locally in the browser so it works without a server account. The project focuses on speed, clarity, and reducing unnecessary steps. It is intended for students, teachers, freelancers, and anyone who wants a straightforward way to plan the day.

StudyTime Session Tracker

StudyTime is a small web application for tracking focused study sessions and short breaks. A user chooses a subject, sets a session length, starts the timer, and records completed sessions during the day. The app can show how much time was spent on each subject, helping students see where their attention is going. The design keeps controls large and simple so the timer is easy to use on both phones and computers. Rather than adding many productivity features, the project concentrates on one purpose: helping users build consistent study time and review their progress without creating a complicated schedule.

BudgetPocket Expense Checker

BudgetPocket is a lightweight expense-tracking web app for people who want a quick view of everyday spending. Users enter an amount, choose a category, and add a short note. The app totals expenses and can summarize how much was spent on food, transportation, bills, personal items, and other categories. A simple monthly view helps users notice where money is going without requiring accounting knowledge. The interface is intentionally direct, making it suitable for beginners who may find full finance applications overwhelming. The project demonstrates how a small browser tool can encourage better financial awareness through simple, repeatable recording habits.

QuickGrade Score Calculator

QuickGrade is a browser tool for teachers who need to calculate scores, percentages, and basic grade equivalents quickly. The user enters the total number of items and a student score, and the app immediately displays the percentage. Additional fields can be used for several activities or weighted components when needed. The interface avoids unnecessary menus so it can be opened and used during checking or class preparation. It is designed as a practical utility rather than a full student information system. The project shows how a focused web application can save time by automating a small calculation that teachers perform repeatedly.

ReadList Personal Library

ReadList is a simple personal reading tracker for books, articles, research papers, and other materials a user wants to finish. Each entry can include a title, category, reading status, short note, and optional priority. The app separates items into planned, currently reading, and completed sections so the list remains easy to review. It can be useful for students handling academic readings as well as general readers managing books and saved articles. The project emphasizes organization without requiring an online account or complex library system, showing how a small web app can make a personal information habit easier to maintain.
