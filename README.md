# DAVE GAURINO

**Ideas, Projects, and Digital Work**

A GitHub Pages-ready static personal website built with HTML, CSS, JavaScript, and local image files.

## Main pages
- `index.html` — homepage with 5-slide rotating feature area and latest posts
- `about.html` — About Me page
- `portfolio.html` — Portfolio page
- `products.html` — Products page
- `blog-archive.html` — all blog posts
- title-based `.html` files — individual articles

The homepage slider advances automatically every 10 seconds.
